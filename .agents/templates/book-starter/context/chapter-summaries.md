# Chapter Summaries (the book's working memory)

Drafting agents read this file **instead of** other chapters. Keep each block ≤120 words.
Update a chapter's block every time `draft-chapter` or `repurpose-blogs` runs on it.

Block format:
- **Core claim:** one sentence
- **Key model or idea:** name + one-sentence definition, or "none"
- **Terms introduced:** comma list
- **Sources cited:** citation keys used (from `[@key, p. N]`)
- **Promises/forward refs:** what this chapter says later chapters will cover
- **Author TODOs:** count of `[AUTHOR: ...]` notes
- **Blog slugs:** (added by repurposing, if on)
